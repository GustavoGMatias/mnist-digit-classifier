## About the Project

This project explores the development of a handwritten digit recognition system using the **MNIST dataset**, a well-known benchmark in Machine Learning and Computer Vision.

The goal is to build a classifier capable of identifying handwritten digits from 0 to 9, progressively exploring different Machine Learning approaches and understanding how models learn from image data.

The project follows a gradual, hands-on learning approach, moving from fundamental concepts to neural networks and Deep Learning.

## Objectives

- Understand the fundamentals of image classification.
- Explore data preprocessing and visualization.
- Implement traditional Machine Learning classifiers.
- Understand neural networks and their learning process.
- Evaluate model performance using appropriate metrics.
- Compare different approaches to handwritten digit recognition.

## Dataset

The project uses the **MNIST dataset**, which contains:

- 70,000 grayscale images of handwritten digits.
- 60,000 training images.
- 10,000 test images.
- Image dimensions of 28 × 28 pixels.
- 10 possible classes (digits 0–9).

Each image represents a handwritten digit, and each label indicates its correct numerical value.

## Development Roadmap

- [ ] **Stage 1 — Dataset Exploration**
  - Load and understand the MNIST dataset.
  - Visualize handwritten digit samples.
  - Explore image dimensions, labels, and pixel values.

- [ ] **Stage 2 — Data Preprocessing**
  - Normalize pixel values.
  - Prepare training and testing datasets.
  - Understand the importance of preprocessing.

- [ ] **Stage 3 — Traditional Machine Learning**
  - Implement an initial classification model.
  - Explore model training and prediction.
  - Evaluate classification performance.

- [ ] **Stage 4 — Neural Networks**
  - Understand neurons, weights, and biases.
  - Implement a basic neural network.
  - Train and evaluate the network.

- [ ] **Stage 5 — Model Evaluation and Comparison**
  - Analyze accuracy and loss.
  - Explore confusion matrices.
  - Compare traditional Machine Learning and neural network approaches.

- [ ] **Stage 6 — Improvements**
  - Experiment with different architectures.
  - Investigate model optimization.
  - Explore possible improvements in classification performance.
